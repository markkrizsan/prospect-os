# E01 — Evidence-Led vs Dialogue-First

E01 is subordinate to the current Prospect OS `OPERATING_CONTRACT`. It changes only first-message strategy. It never changes qualification, READY acceptance, recipient verification, manual sending, production output requirements or continuity rules.

## Hypothesis

For cold, highly qualified B2B prospects, a short research-informed question may generate more positive replies than a complete evidence-led first email because it reduces reading burden and invites a low-friction dialogue.

## Arms

### E01-A / EVIDENCE-LED
Concise verified observation → commercial relevance → bounded useful offer. Internal research/framework language is sanitized before prospect-facing copy.

### E01-B / DIALOGUE-FIRST
A short research-informed question referencing the verified problem class without explaining the entire case. It is not required to be literally nine words.

## Fixed variables

Do not intentionally vary:
- qualification criteria
- strict READY/readback standard
- sender/from address
- recipient verification standard
- subject-line methodology
- sending window
- follow-up policy
- manual Zoho send process

## Assignment

Approximately 50/50, sticky, balanced within Founder-Minute Priority where possible. Experiment Tag is the source of truth.

Historical initial canary cohort:
- A: V10-O042, V10-O045, V10-O047, V10-O049
- B: V10-O043, V10-O044, V10-O046, V10-O048

Those eight records are historical experiment setup, not a current production stopping rule.

## Metrics

Primary: positive replies / sent.

Secondary:
- meetings / sent
- proposals / sent
- wins / sent
- revenue / 100 sends

Guardrails:
- negative replies / sent
- opt-outs / sent
- bounces
- deliverability incidents

Do not optimize opens.

## Decision cadence

- 4 per arm: safety observation only.
- 30 per arm: directional review.
- 50 per arm: early comparative signal if effect is large and quality is consistent.
- Continue toward 100+ per arm before durable policy changes unless one arm is clearly harmful.

Do not add a third arm until E01 has enough observations to avoid fragmenting an already-small sample.

## Interpretation

A variant does not win merely because it gets more replies. Prefer downstream economic outcomes. A high reply rate with fewer meetings is not an improvement.
